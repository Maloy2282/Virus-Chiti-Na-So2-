ВАЖНО:

Версия с читами работаает исключительно на Windows и не более!!! Обязательно скачать python и pip!!!

Инструкция по установке:

1. Полсе скачивания папки .zip и архивовки его заходим в терминал

2. Прописываем команду cd Ваш/Путь/К/Папке/С/Файлом/Launcher.py

3. Прописываем команды: 

pip install tkinter

pip install ttk

pip install pillow

4. Пишем python Launcher.py (если пишет недостаточно такой то библиотеки - скачайте ее таким же образом, как в пункте 3)

5. В лаунчере ищем папку с LauncherSo2.bat, выбираем файл .bat и жмем установку

6. После установки жмем "Открыть игру"

7. Наслаждайтесь игрой с читами от @TyronDev!
